General

“Shuffle the order” shuffles once when the list is built – until the next build everyone sees the same order. “Reshuffle on every visit” also shuffles in the browser, i.e. every time the home screen is opened. Costs nothing: the list stays cached, only its order changes.
How often the server assembles the list. In between, a page view costs practically nothing.

Libraries

On Library Count

Count = how many items from this library should appear in the banner – a target, not a cap. The build keeps searching the sources until every library has reached its number, and then takes no more. For Seerr this means loading further pages (at most 25 pages, i.e. 500 titles – the list has nothing beyond that).
Example: Movies 10, Series 10, Anime 10 gives a banner with ten current titles from each library.

Sources

On Source Count From year

Count = the maximum number of items this source contributes – an upper limit. Sources are queried in this order until all library targets are met. Example: three libraries at 10 each and “Trending” at 30 – that one source can deliver everything. At 15, the next ticked source has to contribute the rest.
From year = only titles released in or after this year, 0 = all. Useful for “Recently added”: that means the import date, which also jumps when only the record was rewritten – and suddenly a film from 1979 is at the top.

Filters

Applies to the displayed image, not the video. A small backdrop stretched across the full width looks blurry. Items whose image size has not been recorded yet are kept.

Appearance
