MKI Password Policy

Installing the plugin changes nothing about sign-ins or passwords. Rules only apply to users you assign a profile to, and a password change is only required when you ask for one. It is then enforced on the server, so it holds on every client: browser, phone, TV and all apps.
Applies to every user set to “Same as all users” below and to newly created accounts. “No rules” means the plugin checks nothing.

Overview

The plugin never stores passwords and never judges a stored password after the fact; Jellyfin itself only keeps a hash. A password is checked only at the moment it is set. After that the plugin only remembers which rules it was checked against. That is why passwords set before then honestly show “Unknown”.
