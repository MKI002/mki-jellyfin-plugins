MKI Merge Versions

Movies that exist in several resolutions, like 1080p and 2160p, are merged into a single library entry. The highest resolution always becomes the primary version, and TV series are never touched.

How it works

  • Movies are matched by TMDb ID, falling back to IMDb ID. Never by title and year.
  • Runs at startup, every hour, and once the library has been quiet for five minutes after changes.
  • You can also start it in Dashboard → Scheduled Tasks → Library → Merge movie versions (MKI).

Options

Rebuilds existing merges where a lower resolution is currently the primary version.
Only logs what would be merged. Handy for a first check; look for "MKI Merge" in the Jellyfin log.

Run

Starts a merge right away with the saved settings. Save first if you changed something above.
