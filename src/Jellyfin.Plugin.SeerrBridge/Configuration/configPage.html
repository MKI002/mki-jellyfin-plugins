Single sign-on

Anyone signed in to Jellyfin is signed in to Seerr too, with no login form in the frame.
No password is bypassed. The plugin issues a one-time pass (valid for one minute, usable once, bound to the account) and answers Seerr through Jellyfin's own Quick Connect. Users can only sign in as themselves.
Needs Quick Connect enabled and a shared parent domain, e.g. jf.example.org and js.example.org. Plain IP addresses fall back to the normal sign-in.
Leave empty to work it out from both addresses, e.g. .example.org.

Compatibility

Jellyfin 12 only reads Authorization, but Seerr and other older apps send X-Emby-Authorization or X-Emby-Token. Without this, sign-in fails with “Something went wrong” (HTTP 400) and user sync stops at 401. The header is only filled in when it is missing, never overwritten, and grants nothing extra.
