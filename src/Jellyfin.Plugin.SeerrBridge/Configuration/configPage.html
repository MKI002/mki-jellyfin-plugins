Sign-in

Anyone signed in to Jellyfin is also signed in to Seerr when opening it – no login form inside the frame.
No password is bypassed: the plugin issues a one-time pass (valid for one minute, usable exactly once, bound to the account), uses it to sign in to Seerr server-side and answers Seerr's challenge via Jellyfin's own Quick Connect. The pass only allows what the signed-in user can do anyway: sign in as themselves.
Requirements: Quick Connect must be enabled on the server, and Jellyfin and Seerr must share a parent domain (e.g. jf.example.org and js.example.org). It does not work over a plain IP address – then the usual sign-in remains.
Leave empty to derive it from both addresses, e.g. .example.org.

Compatibility

Jellyfin 12 only reads Authorization. Seerr and other older apps send X-Emby-Authorization or X-Emby-Token – sign-in then fails with “Something went wrong while trying to sign in” (HTTP 400) and user sync gets stuck at 401.
This bridge only fills in Authorization when that header is missing. It never overwrites an existing one and grants nobody anything extra: it is the same credentials, just in an older envelope.
